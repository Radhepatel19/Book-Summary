# 📚 Book Summary App

An Android application that lets users quickly explore and listen to book summaries in audio format. Designed for readers who want to gain knowledge in less time.

---

## ✨ Overview

This app provides short and easy-to-understand summaries of books with audio playback support. Users can discover new books, listen anytime, and save their favorite summaries.

---

## 🚀 Key Features

✔️ Browse a collection of book summaries  
✔️ Listen to summaries in audio format  
✔️ Mark and manage favorite summaries  
✔️ Clean and user-friendly interface  
✔️ Fast performance with Firebase integration  

---

## 🛠️ Built With

- **Android Studio (Java)**
- **Firebase (Authentication, Database)**
- **Cloudinary / Cloud Storage (Audio Handling)**

---

## 📲 How It Works

1. Open the app  
2. Browse available book summaries  
3. Play audio summaries instantly  
4. Save your favorite content for later  

---

## 🎯 Purpose

- Save time by consuming books quickly  
- Help users learn on the go  
- Make reading more accessible through audio
